# Minimal software for the open web.

I'm **[WhiteDragon303](https://github.com/whitedragon303)**, formerly WhiteDragon-one. I build compact web and desktop applications, mostly on Cloudflare Workers, and keep each project small enough to fit in a single file.

`Cloudflare Workers` `TypeScript & JavaScript` `GitHub Developer Program member`

## Projects

5 projects

### [relay ↗](https://github.com/whitedragon-software/relay)
A Cloudflare Worker that forwards and rewrites web pages so they load through your own domain.
Cloudflare Workers · one file · JavaScript

### [outbox ↗](https://github.com/whitedragon-software/outbox)
Sends email through Resend from your own domain, with a compose form, send history in D1 and a usage dashboard.
Cloudflare Workers · D1 · Resend · one file · JavaScript

### [webcore ↗](https://github.com/whitedragon-software/webcore)
A minimal AI chat app on Cloudflare's edge. It can ground answers in live web search and keeps a branching history of every regenerated reply.
Cloudflare Workers · D1 · Workers AI · one file · JavaScript

### [daybreak ↗](https://github.com/whitedragon-software/daybreak)
A minimal multi-tab desktop browser with a frameless window, a custom tab strip, and each tab in its own browsing context.
Electron · BaseWindow · WebContentsView · HTML

### [whitedragon-authenticator ↗](https://github.com/whitedragon-software/whitedragon-authenticator)
A single-file TOTP authenticator that generates your one-time codes right in the browser.
Browser · Cloudflare Workers · one file · HTML
